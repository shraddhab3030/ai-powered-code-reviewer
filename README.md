# AI Powered Code Reviewer

An AI-assisted code review platform built with Next.js, Prisma, Better Auth, Pinecone, and GitHub integration.

## Overview

This project is a full-stack application designed for reviewing code, managing pull requests, authenticating users, and syncing repositories.

**Key Capabilities:**
* OAuth authentication via Better Auth
* GitHub repository and pull request integration
* AI-enhanced code review workflows
* Billing and subscription management
* Inngest event handling
* Pinecone-powered vector search and embeddings

---

## Tech Stack

* **Framework:** Next.js 16.2.9 (React 19.2.4)
* **Language:** TypeScript
* **Styling:** Tailwind CSS v4, Radix UI / shadcn/ui
* **Database & ORM:** PostgreSQL (`pg`), Prisma 7.8.0
* **Auth:** Better Auth
* **State & Events:** TanStack Query, Inngest
* **AI / Vector Store:** Pinecone
* **Payments:** Razorpay
